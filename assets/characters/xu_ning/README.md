# 旧三维试验（已停止使用）

本轮只制作许宁。人设为约30岁的男性医护，细心、克制、有原则；站着护住药包，坐着前倾整理绷带。画风参考既有人物设计。视觉结果等待用户验收。

## 查看

双击项目根目录的 `打开许宁模型预览.cmd`。预览支持切换站姿/坐姿、360°旋转、调整观察俯仰与距离、显示独立测试椅、切换绿幕，以及导出当前角度的透明与绿幕两张PNG。导出时自动隐藏测试椅，保留人物。

全部制作和验证在后台完成，未自动打开交互窗口。

## 替换位置的约定

- 单位为米，Y向上。站姿全高1.75m；坐姿保留合理身体比例，不放大到站姿全高。
- 两份GLB都带实际命名节点 `GroundAnchor=(0,0,0)` 和 `SeatAnchor=(0,0.46,0)`。
- 站位使用脚底地面锚点，坐位使用距地46cm的座面锚点；不同人物须按这一约定校准，不能依照图片包围盒中心替换。
- 人物GLB不包含测试椅，椅子由独立节点提供。实际场景尚未插入本角色。

## 生成与验证

按用户要求后台执行。参考图使用既有Harness图片编辑接口，模型 `gpt-image-2.5-flare`，真实上传参考附件，站坐原图实际均为1024×1536。没有操控Harness桌面会话。随后复用车辆的本地ComfyUI/TripoSplat重建流程，生成真实三角网格，校正方向、后仰、坐姿前倾和椅子中心，保留原始模型。

已用Godot 4.7.2实际OpenGL渲染检查两种姿势各25个角度；检查顶点属性、索引、脚底高度、命名锚点和画面边界。实际触发了预览的姿势切换、旋转、独立椅显示和PNG导出，运行无错误。

当前交付是两份可切换的静态模型，尚无骨骼和连续动作。单图重建的面部、手指和不可见表面精度低于原始设计图，适合先验收造型、体态与场景显示方式；近景精细表现还需修模。其他七名角色等待这版样张反馈后再制作。
