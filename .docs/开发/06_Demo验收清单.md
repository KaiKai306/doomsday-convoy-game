# Godot可玩框架验收清单

基线为2026年10月15日0.6.0，Godot 4.7.2，最终总稿优先。旧十日原型161项规则、819项界面结果是历史记录，不用于证明本版完成。

## 已实现并验证的范围

- [x] 主菜单进入二十天引擎、自动保存与继续、暂停、返回与确认整日重试。
- [x] 正式开局五人、七项资源、个人状态、实际人口配给和载重。
- [x] 一次晨间准备、每日两项主要事务、唯一营地行动；非法命令及成本不足回滚。
- [x] 八个重要节点，第5日信号、第10日救援、专用成本、满员安置及互斥招募。
- [x] 岗位理解与能力、学习接替、临时支持、死亡和当前无解优先级。
- [x] 五部位核心、安装成本、配件效果、双车、分车、货物转移与容器保护。
- [x] 半段进度不重复领奖，出发前维修不赠行驶收益，失车徒步期限。
- [x] 人物事务到期、失窃账、危机去重、阵营冷却和知识正文选择。
- [x] 完成目标后夜间核验，第20日收束不产生第21日。
- [x] 109张卡片预览不结算、不重抽；目标页显示缺项。
- [x] 营地靠近交谈、相反触控抵消、单指与场外释放、失焦清理。
- [x] 960×600、1280×720、1560×720、2340×1080适配检查和本机实际渲染。

## 可重复验证

|测试脚本|结果|范围|
|---|---|---|
|`run_final_rules_test.gd`|40项，失败0|开局、资源、行动、救援、重试和存档|
|`run_final_systems_test.gd`|36项，失败0|方向、岗位、配件、双车、环境、配给与目标|
|`run_final_regressions.gd`|56项，失败0|到期、去重、正文、失窃、半段与连续磁盘读档|
|`run_final_ui_test.gd`|33项，失败0|入口、预览、适配、触控、真实救援与确认重试；图形模式复跑通过|
|`run_final_replay_test.gd`|17结局、1733命令，失败0|从真实开局重放合法命令并比较最终状态|

17条整局资料在 `tests/fixtures/final_endings_paths.json`，没有用直接设置终局状态证明可达。单项规则使用的边界快照另计。磁盘读档覆盖救援后到南边的12日路线，以及第20日收束路线。救援与结局截图使用真实路线状态。

执行 `tools/check_final_game.ps1 -GraphicalUI`。日志在 `.godot/final-checks/`，截图在 `.godot/final-qa/`，开发记录选图在 `.docs/开发记录/素材/2026-10-15/`。
