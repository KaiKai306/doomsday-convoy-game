# Demo 验收清单

当前基线：2026-10-10，0.2 五日体验切片，Godot 4.7.2。

## 已验证

- [x] 中文主菜单、新游戏、继续存档、退出确认和返回菜单。
- [x] 早晨状态、2–3 条事务以及一次准备行动。
- [x] 安全 / 资源 / 未知路线分别提供不同收益，预设影响代价。
- [x] 约七秒自动行进，暂停停止进度，读档恢复进度。
- [x] 道路事故改变耐久，噪音积累引来异变兽并造成损伤。
- [x] 停歇逐条回应独立事务，选择前显示代价与后续影响。
- [x] 接受 / 拒绝 / 延期改变次日事务和道路风险。
- [x] 维修、阅读、教学与记录、休息改变实际状态；一次主要行动。
- [x] 夜间配给和因果复盘；不可重复执行营地行动或领取补给。
- [x] 阅读后两次教学形成共同维护习惯。
- [x] 五日“仍在路上”“知识的火种”结果可达。
- [x] 配给不足、耐久归零、信任归零、疲劳极限及无法支付任一路线燃料时可结束。
- [x] 存档版本 2 的 JSON 往返、随机状态、事务游标和新增状态恢复。
- [x] 坏存档和旧版存档拒绝，不破坏当前游戏。
- [x] 1280×720、960×600、1560×720 实际渲染截图检查。
- [x] 页脚、推进按钮、移动预设和消耗摘要固定显示。

测试入口是 `tests/run_day_loop_test.gd` 和 `tests/run_ui_test.gd`，运行方式见 README。界面测试包含主菜单指针点击与其他按钮命令流程；截图验证使用本机 Godot 图形渲染。

## 未验收或未实现

- [ ] 安卓导出、真机触控尺寸、系统安全区和低端设备性能。
- [ ] 队长在侧视休息点走动、靠近成员并交谈。
- [ ] 个体健康与疲劳、招募和完整成员关系。
- [ ] 徒步起步、车辆成长和正式 12–20 天旅途。
- [ ] 具有独立玩法的停歇点；目前五处地点是不同场景地标。
- [ ] 完整个体知识传播、制度形成和完整结局内容。
- [ ] 正式背景、音频、插画和随包发布的中文字体。

资源正好支付当晚配给时可以继续寻找下一日补给；只有本晚配给不足才触发对应结束。五日体验结果是切片收束，尚不是原策划完整结局。
