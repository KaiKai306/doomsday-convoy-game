# Demo 验收清单

## 当前版本必须完成

- [x] Godot 4.7.2 项目可以打开。
- [x] 中文主菜单有标题、纵向菜单和状态区域，版式参考图册。
- [x] 主菜单背景不引用现有示例图，使用 2D 几何占位元素。
- [x] 点击“新游戏”进入第 1 天早晨（固定测试流程已接通）。
- [x] 早晨能显示资源、成员、车辆和 NPC 事务摘要。
- [x] 路线选择能在安全 / 资源 / 未知之间选择，并显示预计代价。
- [x] 移动阶段能自动结算燃料和一种即时突发。
- [x] 停歇阶段能完成一次三选一对话，并记录结果。
- [x] 营地行动能改变至少一个资源或车辆状态。
- [x] 夜间结算能显示当天因果链并进入第 2 天。
- [x] 暂停菜单能保存和读取当前 Demo 状态。
- [x] 主菜单和每日 Demo 会按横屏视口安全边距缩放。

## 体验要求

- 横屏 1280×720 下文字和按钮清晰可点。
- 触控按钮尺寸适合手指操作；键鼠只作为开发期辅助。
- 每次选择后，玩家能在当前界面或结算界面看见变化。
- 所有占位背景都带有明确的“待替换”标记，避免被误认为正式美术。
- 目前已通过 Godot 无界面启动验证；尚未完成真实手机触控验收。

## 暂不纳入 Demo

完整战斗、完整设置页、六种休息点背景、车辆升级树、书籍传播的全部规则和 13 种结局插画。
