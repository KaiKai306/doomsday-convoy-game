## 接手后的第一步

1. 用 Godot 4.7.2 打开项目，运行主场景，确认主菜单三枚按钮都能更新右侧状态文字。
2. 阅读 [整套玩法流程·完整版](../设计/整套玩法流程_完整版.md) 和 [Demo 验收清单](./06_Demo验收清单.md)。
3. 把“新游戏”按钮接到第 1 天早晨场景或阶段面板。
4. 每完成一个阶段，就更新本文件的“已完成 / 未完成 / 下一步”，并提交一次 Git。

## 注意事项

- 这是 2D 手机端 Demo，先做信息层级和交互，不引入 3D 节点或复杂渲染。
- 设计图册中的图片是排版参考，不是当前 Demo 的背景资源。
- 不要把临时测试数据散落在 UI 脚本；规则和状态应放在 `src/core/`，界面只负责显示和发出操作。
- 不要重写三份设计原文；实现结论写入 `.docs/开发/`。
- 如果设计发生变化，先在 [设计决策记录](./04_设计决策记录.md) 写清原因，再修改代码。
