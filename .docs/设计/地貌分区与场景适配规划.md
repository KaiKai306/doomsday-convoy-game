# 地貌分区与场景适配规划

2026-10-16。状态：本轮制作与接入已完成。12类主体、7项待补通用地貌及重复事件适配共41套新背景，详细范围与实测见[本轮交付说明](../美术/地貌与地点补齐_20261016/交付说明.md)。下文保留规划依据；实现差异以交付记录为准。

本轮以用户提出的日期划分为规划依据：除特定剧情现场外，第1—6天森林，第7—10天沙漠，第11—14天森林，第15—20天雪地。这是三种地貌、四段旅程。下文的森林分型、跨区表现和制作拆分是配套建议。

剧情地点及进入条件继续对照[最终剧情与地图对应表](剧情地图对应表.md)和最终总稿；新的地貌规划优先于旧版“选择北方后短暂显示雪地”的美术安排。正式界面已通过biome_catalog.gd完成替换；旧location_catalog中的北行规则仅保留为兼容代码。

完整地点名录见[剧情全部地点与地貌归属清单](剧情全部地点_地貌归属清单.md)，补齐15处固定取件地标、15类随机拆检来源及事件局部现场；不局限于现有12个背景场景。

## 四段旅程

|日期|地貌基线|建议的视觉特征|通用场景|剧情现场的适配|
|---|---|---|---|---|
|1—6|森林A：低地阔叶林|灰绿阔叶树、灌木、潮湿土层、破损公路与零散乡村设施；保留废土荒废感|森林公路、林间路边停歇、林间篝火营地|第1天森林边缘加油站；第4天林区废弃医疗站|
|7—10|沙漠|沙土、砾石、干河床、稀疏枯灌木与裸露山体；道路仍可辨认，不必处处堆满沙丘|荒漠公路、荒漠路边停歇、荒漠营地|第7天干旱区旧水塔；第8天侦察及第10天救援站；第9天岑柏所在的荒漠补给停歇点|
|11—14|森林B：山地针叶林|冷绿针叶树、较陡远山、岩壁和山口，人工设施减少；与前段森林有构图和植被差异|山地林区公路、林缘停歇、山地营地|聚落接纳点、中立集市、隧道仍按实际访问和剧情分支出现|
|15—20|雪地|积雪、冻土剖面、覆雪松林、结冰岩壁与冷蓝远山；营地保留暖火光|雪地公路、雪地路边停歇、雪地营地|继续发生的交易、聚落或隧道现场按地点身份适配；雪地本身不代表已抵达终点|

两段森林建议用不同植被与地形区分，而不是只对同一张图调色。第11天重新见到树林可提供短暂缓和，第15天积雪再带来旅程后段的紧迫感；这只是视觉节奏，不额外修改资源消耗或难度。

## 制作拆分建议

优先补齐普通流程的地貌差异，因为这部分贯穿多数日期：

|用途|森林A|沙漠|森林B|雪地|
|---|---|---|---|---|
|公路与普通路边停歇|林区公路|荒漠公路|山地林区公路|雪地公路|
|野外扎营|林间营地|荒漠营地|山地营地|雪地营地|

目标是8套通用外景状态。它们是同类场景的地貌版本，不必全部增加为新玩法地点。路边普通停歇先复用当段公路构图，第9天补给停歇点可补少量后置道具，不额外新增一套站房场景。现有公路、营地和雪地营地可作为制作基础，但目前还不能计为已通过新方案验收。

随后按顺序适配固定地点：开场加油站与第4天医疗站的森林环境 → 第7天水塔与第8/10天救援站的沙漠环境 → 后半程聚落、集市与隧道的实际区域版本。帐篷和救援室内优先复用主体。重复事件需要的跨区版本应在开放相应组合前补齐，不能用明显错误的地貌凑数。

所有外景与现有横版行走改造对齐：水平2D侧视、连续水平脚底线、下方地表剖面，建筑和大件道具置于行走带后方。继续沿用撤车后的正式场景规范；角色和操作控件由游戏实时叠加。地貌方案不覆盖正在制作的摇杆、交互按钮、人物素材或行走代码。

## 跨区和停留的连续性建议

日期段给出主线普通路段的目标区域；实际场景仍由当前地点和行动确定。建议采用以下连续性规则，后续接入时一并落实：

1. 第6天保持森林地表，可在远景减少树木并露出干燥山地；第10天保持沙漠地表，可在离站方向出现远处山林；第14天保持森林地表，可看见高处雪线。过渡不提前占用下一段地貌。
2. 第7、11、15天的跨区发生在实际移动时；该日晨间若仍在前一夜营地，保留原驻扎环境。选择原地停留也保留原地，之后首次跨区移动再进入新区域。
3. 前一夜停在加油站、医疗站、聚落或其他已到达支点时，日期推进不使建筑和地貌自动迁移。已经实际访问的固定地点保留自身区域。
4. 路线预览可以展示目标路段地貌，但应沿用现有预览标识；查看目标或切换标签不等于真实抵达。
5. 保存继续、重试当天、主界面与全屏行走应保持同一地点及地貌。后续实现若增加区域状态，需要兼容旧存档。

因此，日期分区适用于普通旅程的推进，特定剧情现场和确实留在原地的情况优先保持位置连续。以上跨区时点是建议，不把它写成已经由用户确认或代码实现的规则。

## 后续接入验收要点

- 新游戏首屏是森林边缘加油站，首次出发前不显示营地。
- 普通旅程分别覆盖森林A、沙漠、森林B、雪地的公路与营地；雪区不能只有营地图。
- 第4天医疗站、第7天水塔、第8天侦察和第10天救援的触发与现有剧情一致。
- 第6→7、10→11、14→15天覆盖晨间、出发、停歇、扎营及原地停留，检查跨区时点。
- 聚落、固定登记处等不会因为跨日期而迁移；同类随机事件使用其实际区域的版本。
- 主界面、行走、保存继续和重试当天的地点/地貌一致；地貌展示不改变随机状态、成本、救援门槛或结局条件。
