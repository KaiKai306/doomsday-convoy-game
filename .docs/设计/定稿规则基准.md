# 末日车队正式设计规则基准

版本 1.1　2026年10月15日。车辆配件采用五部位三十种成品的并入版。正式设计以本文件的数值和判定顺序为共同基准，替代十日原型与旧剧情规范中的冲突规则。策划正文、事件卡和流程图同步采用本基准；代码实现属于后续工作。

## 产品与叙事边界

安卓横屏单机，HD-2D；旅途和面板为俯视，营地探索与交谈为侧视。单局目标45至75分钟，普通日3至5项核心决定。五人带旧车出发，最长20天；第2、5、8、10、12、15、18、20天固定重要节点，第10天最重要。第3、4、6、7、9天资源支路只改变资源、耗时和既有风险，不改主线承诺；独立事件仍能造成伤亡、招募和关系后果。第1天为教学，不设主线分叉。

第5天固定收到妹妹正式求救；可用旧电台是开局装备，不因未抽到电台卡而取消主线。此前只有模糊线索。第10天实际救援，距第5天经过5天；准备和当天方案决定结果，不掷妹妹生死骰，不提供当日替代救援。妹妹获救后继续游戏。主线保留救援、车队关系、生存、知识与巨大轮廓；核武与反应堆只作为旧世界背景，不产生并列主线或新结局。

## 数值和计数

所有角色健康、疲劳、个人信任、四项岗位能力为0至100；健康0死亡、1至29重伤、30至49伤员、50以上可执行救援岗位；疲劳80以上当夜健康−5，疲劳95以上不能执行岗位任务。个人信任代表对队长可靠性的判断。好感0至100独立记录，代表亲近程度，不把所有信任变化再次自动结算成好感。全队信任取存活队友个人信任的四舍五入平均，无队友时沿用主角自信值50。好感均值不含主角，若无队友则为0。群体差为两个至少各有一名存活队友的群体的平均信任差绝对值；只有一个群体时为0。成员归属固定为撤离A或公路B，妹妹归公路B。制度进度0至6，知识0至100，理解度每书每人0至100。噪音、暴露、追踪、私藏风险均0至100。所有连续次数都注明具体行为；死亡、永久招募互斥、主线历史不回写删除。

原稿健康和疲劳若采用0至10小尺度，阈值和增减统一乘10；信任和岗位值不乘10。原卡已使用百分比耐久、岗位值的保持同一尺度。超过上限截到100，低于0截到0；资源扣款先验算，不能用截零支付本来不足的成本。伤害后立即按同一批次检查死亡，不等到次日。

人口N含主角和所有已加入的存活成员；队友数C=N−1。最大N=8。招募前可满8，不预留妹妹席位；第10天满员救出妹妹后，在登记加入前明确选择一名现有队友离队，否则妹妹留在救援点，记录“获救但未随行”。不允许主角离队。离队不等于死亡，无药品或技能的人员不被强制写死。

## 每日与资源

一天：晨间自动存档→状态摘要→一次准备行动→路线及预设→固定主线或最多一次移动随机事件→停歇探索与最多两项主要事务→一次营地行动及最多一张营地卡→夜间配给和状态→结局检查。固定主线不占随机卡池；第5、10天使用主线移动场景，不再叠加移动随机事件。追问只揭示信息，不额外结算成本；事务最终接受或拒绝各结算一次。营地事件是同一行动的延伸，不能再次执行完整基础行动的同一收益。

每日配给按夜间实际人口支付：水N、食物N；不是五人固定值。完整配给疲劳−2。缺水每人健康−15、疲劳+10；缺食每人健康−8、疲劳+5；同日两者可叠加，物资按公平优先分配，接受特殊分配时按个人实得缺口结算。连续两天缺水额外健康−10，连续两天缺食额外−5；缺口在晨报和分配前显示。健康≥50、疲劳<80且足额配给者夜间健康+2。每次普通行驶全员疲劳+6；主动停留+2；徒步+20。休息行动全员疲劳−20；定向照料药品1、目标健康+25疲劳−10；维修零件3、耐久+15；基础分水水2、全队信任+2。晨间五行动分别为分水、零件2耐久+8的小修、清账使私藏风险−10、药品1健康+20的急救、不行动；不行动连续3天全队个人信任−5，计数清零后重新累计。

每个停歇点有一次可见当地搜集：选择水18、食物16、燃料20、零件6或药品2中的两项地点实际提供项之一，占营地行动。地点供给只领取一次。供给带：1至4天水/食，5至7天燃料/零件，8至10天药品/食，11至14天水/燃料，15至17天食/零件，18至20天水/药；资源路段可选供给带中同类收益。重要日选择北、南、东区域后，只覆盖随后两天的供给类别：北药品/食物、南燃料/零件、东饮水/食物；收益数值不变，当日类别不追溯改写，下一重要节点覆盖新的随后两天。选择保持当前方向但未选区域时不重复刷新覆盖期。该修正不替代救援线索和真实距离。

货重：水每升1千克、食物每份0.5、燃料每升0.8、药每剂0.1、零件每件1、书每册0.5、茶香每份0.1。只计货物不计座位乘员，油箱燃料也计货载；超载禁止出发，可丢弃/交换/存放，丢弃确定不可追回。额外车日常燃料以4为基础再按其配件修正、每日耐久损耗按各车独立，队伍最多2辆且人口仍最多8；救援门槛看主车，不能用别车重复支付消耗。重建取得的新车默认耐久50、8座、五部位原厂状态。

## 岗位与知识

合格岗位：能力≥60、健康≥30、疲劳<95。见习能力40至59可以做普通任务，任务成功率少10个百分点，不能满足救援60门槛。岗位死亡时立刻查接替者；没有合格者但有见习，可花零件2或药品1支持一次相应维修或医疗任务，24小时内通过学习使能力达60才算持续接替。没有维修岗位且车耐久>40可继续至下个营地，无法修理必须提示；没有医疗岗位且无人健康<30不立即结束。仅当必需任务已经发生、没有任何可行接替或求助才触发关键成员死亡。侦察/后勤空缺造成风险+10百分点/交易成本+2对应物资，不单独立即结束。主角可以学习接替，保证独自抵达在条件上可达。

阅读2小时，使对应理解+25、知识+5；教学2小时，教师岗位≥60且对应理解≥50，成功率=min(95,max(5,教师能力−20+floor(学习者信任/5)))%；成功学习者能力+10、理解+15、知识+5，失败能力不变、理解+5、知识+1。连续两次成功且学习者能力已≥50，第三次教学固定成功并能力+10；完成第三次则三次连续计数清零。失败将连续计数清零。记录一次消耗1页，初始笔记本20页，知识+4，得到具体永久记录标签；重复抄同一记录只恢复可读性，不重复知识。标准交换书获得水10或食8或零件4，交易+1，关系+5；焚烧未传播书获得温暖标记、当夜全员疲劳−10，知识−5、书永久消失；已记录知识不因书焚烧扣除。

公开规矩每次完成一次公平分配且有A/B各一名赞同者制度+1，每天最多1；制度≥3且两群体平均信任≥50时形成公开制度，私藏风险−10。茶仪式水2茶1，全队好感+3、追踪+2；香仪式香1，全队疲劳−5、暴露+3；连续3次同种仪式形成习惯，全队信任+3且计数清零，不能每天无消耗重复。

## 概率算法

### 行动占用与时间的统一口径

普通群体决策、公平交易、贡献、玩家安排的群体分流和完成目标各耗时1小时；短库存答复、个人换班各0.5小时；卡片明确列出时间时优先使用该值，不再叠加一份通用时间。追问、查看状态、灯光或密封预设的确认不另收费。所有事务仍占原有额度，完成目标属于主要事务，不占营地；书籍交换、换车、安装模块属于唯一营地行动。每日实际总时长超过12小时时，全员疲劳增加2×超出小时，0.25或0.5小时按比例结算，允许小数，不隐性向上取整。

M01拆前桥替代当天准备，总耗时2小时；M02分配零件小修替代准备，总1小时，两者完成后不再另领晨间准备收益。M05/M06/T05治疗、T03完整维修、T07全队休息、N-F04①用药均占唯一营地行动；未单列时间的完整行动2小时加答复0.5小时，共2.5小时。紧急行动可在出发前执行，晚间只能显示已经使用的动作，不再执行一次完整行动。T02/T10个人离岗换班只占0.5小时事务，不是全队休息，晚间仍可选择营地。已使用替代营地动作后，普通交易、贡献或目标登记可以在尚余主要事务内完成，不能再次维修、治疗、搜集或学习。

第4、7、9日固定招募预留唯一停歇机会槽。同日N-F08哨卡复核转人物危机，占白天两项主要事务之一，未处理仍按其默认后果结算，不再赠第二机会槽。N-F07第二个夜间强制后果在夜配给后呈现：调停耗1小时并按剩余库存付水2食2，安全分流耗1小时且须同意、接纳点与移交；明确各走各路无额外行动时间，不假称所有离开者均安全。第三晚C30只以各50%建立下一日一个原因，不能同晚再抽第二营地卡：N-F01在次日晚替代营地，N-F02在次日作为人物危机占白天额度。

### 昼夜与环境预设

每天08时开始，进入移动阶段时，已累计时长加本段预计移动时长超过10小时，即本段会进入18时后的夜间，才允许夜间移动事件入池；不能用尚未执行的晚间营地行动倒推先前移动为夜间。事件新增耗时若令随后仍需行进的路段跨过18时，只影响后续实际阶段，不重抽本次移动事件。12小时预算是疲劳阈值，18时是昼夜边界，两者分别记录。

开局车灯关闭、食物已密封、无气味原因。路线预设可确认照明，默认关闭；打开后记录灯亮，关闭后立即清除，不附加未写明的技能收益。休息行动附带密封确认，默认密封，不另占动作或时间；玩家取消密封且仍有食物才留下次日食物气味，任何实际密封操作或V03处理后清除该原因。守夜照明按真实开关写台词，不能默认灯亮。V03只有夜间、噪音≥50、灯亮及上晚未密封气味同时成立才入池，仍使用路段整池概率，不额外自动夜袭。

D100是均匀整数1至100，结果≤p成功。p=0不抽必失败，p=100不抽必成立；不存在把所有概率统一夹至5%至95%的总规则。只有显式技能公式使用其上下限。加成用百分点，概率最终限制0至100，所有加成按卡所列一次计算，禁止重复独立掷同一事故。

晨间人物候选按每个存活角色分别生成：每个角色只检查自己的最高非空层，危机100%、承诺70%、普通35%、无候选0%；该角色出现后，在自己的同层m张卡中等权选一张，每张条件概率100/m%。再将各角色已生成的候选按危机优先→最早截止→最长未处理→稳定ID排队；不能跨角色再抽一张替代此排序。白天最终最多处理两项主要事务，人物和停歇机会共同占用此额度。落选危机按到期后果处理并在晨报显示，非危机顺延最多1日。原停歇人物事务与晨间新增事务共用这一轮，不各抽一次。妹妹及新成员使用各自基础事务池，缺席或死亡角色无候选。N-F07第二夜的强制后果选择是夜间专用例外，不占白天两项，但仍扣实际成本和耗时。

队列排序规定呈现先后，玩家仍可在截止前选择最多两项主动处理；没有选中的危机不会消失，按各自截止和默认结果结算。示例优先处理医疗而略过另一项只是玩家选择，不是改变随机权重或免除处罚。

移动池先纳入强制机械状态事件：耐久≤20触发抛锚100%，但抛锚不等于报废；排除普通移动抽取。其余先按路段出现率整池掷一次，再按候选卡等权抽一张。天气D100每日一次：晴1至60(60%)、雨61至80(20%)、雾81至90(10%)、沙尘91至100(10%)。无合格卡出现率0%。同池m张卡条件概率每张100/m%，允许以分数精确记录，不写“约”。主线日5/10仅天气保留，主线结果不被普通移动卡打断。

營地卡按危机100%、未兑承诺70%、普通35%、无卡0%选最高非空层，仅在该层等权抽一张；只有当晚所选行动适用。卡收益表默认写“基础行动之外的追加变化”；若替代基础收益则显式写“替代”，当晚不再加两次。路边遭遇归移动事件或停歇机会槽，每天最多一个停歇机会槽，出现率资源35%、安全20%、未知40%，当日强触发停歇危机则100%并替代普通机会。机会行动占两项主要事务之一，不自动再赠一次营地行动。

同一普通卡冷却3个完整日、同一人物连续两日不重复同一普通卡、一个普通卡每局最多3次；一次秘密、互斥招募、首次轮廓、死亡纪念只一次。危机冷却0但同一原因已解决就不再入池；未解决最多次日升级一次，此后进入具体到期后果，不无穷重复同一句。拒绝有后果但没有全体NPC无条件处罚。

抛锚机会只判一次：基础安全5%、资源10%、未知18%；雨+10百分点，未修前桥+12，耐久21至40再+15；低噪音−5；最终0至60%。它是抽中机械风险卡后的选项概率，不每日额外独立判一次。当天小修/完整维修后前桥历史清除；卡指定延期提高概率用+12替代旧18→30，不再与同一前桥加成叠加。报废只在耐久0、明确烧毁或断轴不可修结算时成立；车辆报废不得一律按健康事故翻译。

|E12|南边的灯|第10天妹妹实际救援成功，妹妹仍存活且加入；12日起实际到南边定居点并选择一起留下，重逢段放在第10天不重复|

无车状态不能在期限后进入需要车的黑旗、车队之王、商队、敌影同行；共同体/南灯/独自抵达必须在实际可达期限内完成，不能因为选了远方目标而跳过距离。候选冲突先处理同批死亡和即时无解，其余按实际完成动作选唯一主结局。妹妹命运附加到全部17种主结局：若全队死亡，获救后死亡尾声成立；不以尾声遮蔽主结局。

## 保存与验收

每日开始生成唯一自动存档，允许离开后继续当前进度；“重试当天”从当天开始快照还原，使用新的随机种子重新生成随机事务、天气与支线，同一重试内已抽结果固定，防止打开关闭菜单免费重抽。固定第5信号、第10条件、互斥历史及之前所有日的状态不重抽。正常无任意时点手动回档；重试必须明确提示会放弃本日进度，不能只重掷成功率保留本日收益。结局后允许重试最后一天或重新开局，不能从重试当天还原更早的互斥招募。

一个存档载荷包含晨间快照day_start和当前阶段current；阶段结算后自动写current，包括已生成的随机结果、选项与库存。继续旅程读取current，重试当天只读取day_start并换种子。所有不可逆指当前尝试内，历史上一日及以前的死亡、互斥选择不能回写；整体重试当天会撤销本日全部结果，包括本日死亡和招募，不允许保留其中有利部分。健康0结算后不能复活；药品、外援的补救必须发生在重伤尚未死亡时。正常终局完成动作先锁意图，夜间配给和死亡检查后才进入尾声；即时死亡与无解优先，不能通过点定居跳过当晚必要结算。

救援日燃料12和耐久8均为整日专用成本，替代普通路段燃料与路损，也不再叠加低噪音预设燃料2；正面突破只追加已列件2与耐久10。执行者疲劳10按实际参与成员去重，只会给兼任医疗侦察者一次；全队基础旅途疲劳6仍一次。早期徒步E02是第12天夜间完成的正常收束，提前抵达避难点可休整等到12日，不会强迫继续走；失车期限只控制游戏日的最长延续，不要求抵达当日就死亡。E13须有可用车。妹妹首次救援地点为外围救援站，南边的灯目标是之后实际进入南边正式定居区，两次抵达不等同。

全队死亡仅指当前在队名单，妹妹已安全离队时不自动追加她的死讯，尾声以她最后确认的真实状态为准。安全离队为S01安全离队版，救后实际死亡为S02，救后自行离队但去向与安全未确认为S04救后去向未知版；不能单凭当前名单是否有她推断生死。玩家安排的安全离队可以作为一次公开群体分流事务完成多人选择，须每人同意并到已确认安全接纳点，明确资源移交；不是为了减少配给随时删人。T15拒绝协商后的100%自发离队是NPC自己的行为，不受安全点前提豁免，不保证安全，也不凭空生成死讯。M14的25%只判是否提出离队并进入协商，不直接删除人口；协商未完成者照常配给。已收到信号尚未作第10决定而提前结束，妹妹尾声为失联，不自动算主动放弃。

封闭隧道N-C04只要实际到已标封死入口且仍准备穿越即100%物理危机；低耐久≤20/追踪≥80是风险提醒，不是让好车能穿封死出口的豁免条件。仍强冲明确全队死亡；退路与弃车都可避免。V10有真实已标火源时可以全员无伤撤离弃车，燃料0并按搬运清单弃货；N-C02/N-C03在追兵直接可见时可以替代追踪门槛，仍需其卡其他条件。报废后如保留书、本、茶或香，全部计搬运重量，不能只检查食水重量。

再走不能是补救半径和救援时间耗尽的强制失败分支；到期后不开放新的可操控日期，即使库存尚有少量物资也不能越过荒原继续抵达远方。结局镜头呈现最终失去行动能力，不要求在到期前先用一次人为伤害把所有健康扣至0，也不将该非突发失车结局错判为E01。此前明确预告最近接纳点/废车点距离及截止夜。

验收区分规则检查、人工故事审读和未来游戏实机平衡。数值演练记录具体每日抽取、选择、成本、资源、存活、知识、关系及最终条件，不把外置满足门槛的快照称为从开局跑通。17个结局至少各有一条合法示例；任何路径中断立即结束，不补出剩余日。保留重大调整表：健康尺度统一、人口配给、固定信号/实际救援、互斥与满员、抽取层级、报废徒步期限、主结局实际动作、读档重新随机。

救援坏项的现场边界：只有已实际抵达救援站外且现场已确认妹妹病危受困时，才显示“强闯救援站隔离走廊”。准备不足、污染警示和无法安全撤离均明确可见；强闯导致妹妹在未能进行有效救护的撤离中死亡、执行者健康−20，立即按同批伤害查死亡。这是救援站的独立场景，不是N-C04完全封死的公路隧道。尚未到站、没有现场确认则只有放弃/失联，不凭空判她死亡。
