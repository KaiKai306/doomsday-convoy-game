版本 1.1｜2026年10月15日｜并入五部位三十配件

本文将剧情整合总版、二十天节奏及正式游戏系统写为同一套设计，并正式并入[车辆特殊零件与改装设计](./车辆特殊零件与改装设计.md)。[定稿规则基准](./定稿规则基准.md)采用相同数值；[完整玩法流程](./整套玩法流程_完整版.md)描述玩家顺序；[示例图册](./末日车队_游戏全流程示例图册.md)保存界面和场景参考；[剧情事件与人物事务定稿](./剧情事件与人物事务定稿.md)保存详细卡文本；[结局与妹妹尾声全文](./结局与妹妹尾声全文.md)保存17个主结局和六种附加尾声。本轮交付为设计规范，现有十日原型尚未实现本文所述完整游戏。

## 一、项目概述

名称：末日车队。平台：安卓横屏单机，开发期兼容键鼠。类型：HD-2D末日生存经营与叙事决策。单局目标45至75分钟，最长20天，普通日3至5项核心决定。

玩家扮演队长，带领四名队友和一辆旧车穿过废土。主要体验来自人物对话、救援、路线承诺和代价；资源经营约束选择，难度适中。玩家应理解缺少什么、为何付出代价、哪些承诺仍来得及兑现。妹妹救援不由隐藏的一次生死骰决定。

救出妹妹、共同定居、加入聚落、成为商队、保存知识或顺从巨大敌影的规律，都可能收束旅程。结局由实际行动和状态确定，不能点击结局名称直接获得。死亡和已兑现的重大后果不可因推进下一节点自动取消。

## 二、世界背景与叙事边界

故事发生在公元2100年的长期末日中。能源开发破坏生态，动植物和微生物异变；旧世界曾试图以核武器解决灾难，污染却使废土更危险。幸存者依靠聚落、车队、临时工路和有限医疗资源生存。

核灾难、废弃反应堆和旧军用设施仅为世界背景与探索素材。正式游戏不再以关闭零号反应堆、启动核武器或消灭深巢母体作为并列主线，也不保留“人类胜利”“核火重燃”“妹妹终结”旧结局。

主线围绕妹妹求救、队员关系、分配规则、生存条件和知识保存。巨大轮廓是可观察巡游规律的外部威胁，不因善意对话被驯化。妹妹是普通人，救出后沿用其他成员的健康、疲劳、岗位和关系规则。

## 三、核心玩法与视角

主要操作在停歇点发生：侧视移动、靠近人物交谈、查看请求，在有限资源与时间内作决定。旅途和状态面板为俯视，营地探索及交谈为侧视。战斗是途中事件之一，不承担连续动作战斗主线；事发后不重开完整装备菜单抹去事故。

循环：每日自动存档 → 状态与昨日因果 → 一次准备 → 路线与预设 → 固定主线或移动事件 → 停歇探索与主要事务 → 一次营地行动 → 夜间配给与状态 → 结局检查 → 下一天。

## 四、二十天剧情节奏

固定重要节点：第2、5、8、10、12、15、18、20天。**第10天最重要，决定妹妹能否实际获救。**第3、4、6、7、9天的路线选择仅改变资源、耗时和已有风险，不改主线承诺。该限制只针对资源支路；独立事件仍可招募、伤亡、离队和改变关系。第1天教学，不设主线分叉。

|天|职责与玩家行为|连续性|
|---|---|---|
|1|五人清点“老伙计”与物资，教学准备、岗位、行进和营地行动|建立初始人物、资源、车辆前桥状况|
|2·重要|选初始方向；核查旧频段得情报1|可影响供给，不代表救援完成|
|3|资源支路、前日请求跟进|只写真实收益、风险、耗时和事务后果|
|4|固定医疗站招募：许宁/陈川/都不收|选人永久互斥；不改变主线承诺|
|5·重要|固定妹妹正式求救，确认坐标得情报1；漏频段者可花零件2补那一来源|正式信号必发生，第10天实际救援，期限不重置|
|6|燃料、前桥和岗位准备；可揭示已知废车点|准备改变门槛，不能删除计时|
|7|固定水塔招募：杜衡/林悦/都不收|永久互斥，提示新增人口配给|
|8·重要|南边入口侦察：燃料4、耗时1小时，情报1|写南线承诺，不直接救出|
|9|最后常规准备，可接触岑柏；显示药品、零件、车况、疲劳与满员缺项|不是免费补齐条件；前期需保留药品2|
|10·最重要|实际救援、主动放弃或承认无法完成|确定妹妹命运；不掷生死骰，之后无首次救援|
|11|承接真实损耗、伤势、满员离队或失联情绪|不能回写第10天|
|12·重要|首次正常终局机会：确认执行目标，实际完成可行庇护或长期行动|早期徒步当晚截止；妹妹历史不变|
|13|执行12日目标、补给、学习、公平分配|已解决危机不重复|
|14|群体关系、知识与调停|分裂看连续两夜状态和明确选择|
|15·重要|承担代价、调整执行方案；商会第二车报价可用|能改变未来做法，不能恢复首次救援|
|16|新方案养护和人口负担|各车和资源独立结算|
|17|结局压力、巨大轮廓记录承接|只累计实际遭遇的新记录|
|18·重要|最终立场：确认可达聚落、商路、建点或巡游通道|承诺不等于完成，显示距离和剩余天数|
|19|最后常规兑现日，行进、配给、修车与照料|不自动延长总天数|
|20·重要|先最后可执行选择，再夜结算与终局|无第21天；无完成目标且无即时结局则无名消失|

提前结束立即停止本局，不补未经历节点。到达地点、交易满4次或达到关系阈值不自动截断；正常主结局还须实际完成动作。

## 七、每日操作与人物事务

|阶段|操作|约束|
|---|---|---|
|晨间|自动存档、昨日因果、天气与摘要，一次准备|危机和救援缺项先提示|
|路线|重要节点决断、当天支路、预设|主线承诺与资源时间分别记|
|行进|固定主线或最多一张移动卡|第5/10天主线替代普通移动卡|
|停歇|侧视探索、最多两项主要事务|停歇机会占名额，追问不重复收费|
|营地|一次行动、最多一张适用卡|卡为延伸，不送第二次完整行动|
|夜间|配给、知识、习惯、承诺、期限和结局|N-F07第二夜强制后果是唯一追加选择例外，20日强制收束|

每日12小时，准备1小时、基础营地2小时。超时仍同一天，全员疲劳增加2×实际超出小时，允许小数，不能延期救援。08时出发基准、18时为夜间；移动事件按进入阶段累计时长加本段预计移动时长是否超过10小时判断，不能由晚营地倒推。普通行驶疲劳+6，主动停留+2，徒步+20；快速额外+4。

晨间五行动：分水（水2、全队个人信任+2）；小修（零件2、耐久+8）；清账（私藏风险−10）；急救（药1、目标健康+20）；不行动（0成本）。连续3天不行动全队个人信任−5后清零。小修清除当前未修前桥历史。

营地行动：休息全员疲劳−20；照料药1、目标健康+25疲劳−10；维修零件3耐久+15；当地搜集；阅读/教学/记录；仪式；模块；书籍交换或换车。普通公平交易、贡献、群体分流与完成目标各占1小时主要事务，不再占营地。完整维修清除前桥历史。M01维修占准备共2小时、M02占准备共1小时；完整治疗/维修/全队休息卡替代唯一营地，未单列时间为2小时动作加0.5小时答复，可紧急提前执行，晚间不再领完整动作。个人排班T02/T10仅0.5小时，仍可晚营地。

每条事务保存ID、人物、需求、目标、对象、紧急度、期限、触发、选项、即时变化、后续、冷却及互斥。延期不是支付或自动完成。已解决危机退出池，拒绝不触发无条件全体处罚。

老张围绕车辆、疲劳、路线可靠性与信任；艾琳围绕药品、伤员、休息与保护；阿杰围绕路线信息、认可、疲劳和补给；索菲亚围绕账目、私藏、公平与离队。扩充卡沿用性格，核对死亡、离队、失约和已知信息，不能让NPC否认已发生事实。

重要日方向覆盖随后两天供给类别：北部药/食、南部燃料/件、东部水/食，收益量仍沿统一表，不另加倍率。选择前显示实际供给。第8天南线承诺之后9/10天可能无当地药品，因此第8天以前提示保留救援药品2；开局药5，不能等缺药后免费补药。供给方向不替代情报、救援入口和真实距离。

地图记录已知点、通路、位置、相邻距离、领取历史和目标可达性。正常车辆每天沿章节前进一条主边30千米，路段表燃料已含该边；快速仍一主边，绕行增加10千米而不多走一章。主动停留不推进主边，补给支路为同章内支边，收益不增加目的地进度。

救援站须第10天、至少6条主边及情报3；正常目的地最后入口须至少8条主边，且12日前不能完成。第12、18、20天出现近程终点入口，只有真实推进至当前目标边才可进入，最后6千米作为当日完成动作、本日行驶燃料已包含，不再扣一次路线费用。停留过多导致12日不足8边，可之后继续推进，但10日救援期限不延长。

第6/9/12天可揭示一次废车点，只有实际走到或徒步可达才取得机会。徒步使用当前位置地图上5至8千米避难点或废车支点，不能把车辆下一章30千米视作每日10千米徒步可达，选择远方目标不能瞬移。

### 8.2 抽取算法

D100均匀整数1–100，≤p成功。0%不抽必失败，100%不抽必成立。加成按百分点一次计，最终0–100%；仅明确技能公式用专门上下限，不套通用5–95%。禁止同事故重复独立抽。

|池|出现判定|抽选|
|---|---|---|
|人物|每角色分别判最高非空层：危机100%、承诺70%、普通35%、无候选0%|每角色同层等权一候选，跨角色按危机→截止→未处理→ID排序；白天含机会最多两事务，N-F07夜间强制另计|
|移动|安全20%、资源35%、未知50%|筛选后整池一次，出现后等权一张，无候选0%|
|机械强制|耐久≤20抛锚100%|替代普通移动，不等于报废|

## 十六、界面、设置与保存

主菜单新游戏/继续/设置/退出，无档继续禁用。安卓横屏设置含动态/静态背景、音量、音效、阅读速度、触屏布局、辅助功能。营地点地与方向触控、近距离交谈；对话/总览/暂停停止移动，返回先关当前面板。

摘要显示天、重要节点、人数座位、货重、资源和夜配缺口。总览显示真实位置与路线、成员健康疲劳岗位/信任/好感/记忆、阵营、知识、制度。选择前明确成本、前置、确定后果和概率，库存不足不能伪装可执行。数值显示来源与实际变化，达到上下限显示实际增减。死亡、互斥、满员离队、放弃、强冲和终局动作前提示不可逆。

每天开始唯一自动存档，退出可继续当前进度。正常无任意时点手动回档；重试当天还原晨间快照、更换种子重生本日事务/天气/支线，同一重试已抽固定。开关菜单不重抽，不只重掷失败而保留奖励。

同一载荷存两层：day_start为晨间快照，current为当前阶段进度。每阶段结算后写current，包括已抽结果、已选选项与实际库存；继续读current，重试只读day_start并换种子。不可逆指当前尝试内及以前各日；整体重试撤销本日全部结果，包括本日死亡和招募，不能只保留有利部分。前日及以前历史不回写删除。

5日信号、10日条件、以前各日互斥/伤亡/资源/主线历史不重抽。重试提示丢弃本日全部进度；结局可重试最后日或新局，不能还原更早招募。10日早已缺失门槛不靠随机重试造替代救援。

## 十七、内容范围与验收

正式内容为20日主线、四人物扩充事务、独立营地卡、移动/停歇卡、招募、岗位、知识、茶香、制度、三阵营、五部位三十配件、失车/换车、17主结局和妹妹尾声。卡库直接保存正文、选项、条件、数值、期限、互斥、后续，不依赖运行时编造新故事。

检查每角色最高非空层出现及同角色等权，移动/营地整池、0/100、冷却、同源不重领、事故一次；检查配给货重、统一救援、接替、即时伤亡、徒步期限、位置和实际终局动作。完整候选池生成与Godot实机仍是后续实现验收，本轮数值演练只验证展示路径和列明边界。

17结局各一合法示例，从开局逐日记抽取、选择、成本、库存、存活、状态、关系、知识和完成动作；不可直接把满足门槛快照称完整跑通。某日终止就不补剩余日。文档算例不是实机平衡已完成，45–75分钟体验和适中难度由后续实机验证。
