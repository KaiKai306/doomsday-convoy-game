玩家第一次游玩视角与系统执行规则

**本文件描述玩家从点击“新游戏”到一局结束的完整流程，供策划、程序、美术、文案和测试统一理解。正式游戏通常在第 12～20 天之间达成结局；资源耗尽、关键成员死亡、车辆报废或车队分裂时，可以提前结束。**

# 一、进入游戏与初始队伍

玩家点击“新游戏”后，看到简短背景介绍：能源开发导致生态崩坏，异变生物占据大地。玩家带领一支小型车队，寻找可以生存和重建家园的地方。

初始队伍只有主角（队长）和四名成员，刚好满足车队运行所需的基础工作分配。四名成员的能力水平都处于基础范围。当前版本不设计成员专属技能，成员差异只通过数值体现。

| **对象** | **初始规则** | **待填写内容** |
|:--:|----|----|
| 主角 / 队长 | 负责路线选择、资源分配、NPC 对话和营地行动。 | 姓名、基础数值和个人背景。 |
| 四名基础成员 | 覆盖车队所需的基础工作岗位，所有数值处于基础水平。 | 具体岗位、姓名、健康、疲劳、维修、医疗、侦察、后勤和信任数值。 |
| 地图潜在成员 | 分布在路线、停歇点、求救地点和特殊事件中；没有特殊能力，只在一项或多项数值上有高低差异。 | 数值范围、招募条件、容量限制和加入后的资源消耗。 |

玩家之后可能通过路线选择、NPC 对话、救援、交易或即时突发事件救下这些成员，也可能错过或导致他们死亡。新成员加入后，会增加人口和每日资源消耗，并改变工作效率、关系网络和 NPC 每日事务。

# 二、玩家第一次游玩的目标

第一次游戏不要求玩家立刻理解所有系统。玩家首先只需要理解一个目标：让车队活过今天，并到达下一处停歇点。随着游戏推进，玩家再逐渐理解 NPC 事务、书籍传播、车辆状态、怪物规律和聚落结局。

界面显示：当前天数、车队人数、饮水、食物、燃料、药品、零件、信任、成员状态、车辆状态、持有书籍、茶叶、香薰和路线信息。

# 三、每天的完整循环

每天通常产生 3～5 个主要交互，其中大部分是 NPC 对话。移动中的战斗、怪物群、道路事故等属于即时突发，不计入对话选择次数，也不给玩家重新打开完整菜单进行长时间规划。

| **阶段** | **玩家体验** | **玩家操作** | **系统结果** |
|:--:|----|----|----|
| 1\. 早晨事务 | 查看资源、成员、车辆、昨日因果链和 NPC 当日事务。 | 查看事务优先级，执行一次准备行动。 | 生成当天 NPC 对话队列和路线可用信息。 |
| 2\. 路线选择 | 查看安全路线、资源路线和未知路线。 | 选择路线和移动倾向：快速、低噪音、绕行或熄火。 | 锁定预计消耗、噪音、危险标签和事件池。 |
| 3\. 自动移动 | 车队持续前进，显示进度和资源消耗。 | 通常不能打开常规对话树；即时突发时执行预设行动或短促反应。 | 战斗、怪物群、道路事故等直接改变人员、车辆、资源和路线。 |
| 4\. 停歇对话 | 按紧急度排列 NPC 对话。 | 回应、追问、承诺、拒绝、交换、让其他成员回答或暂缓。 | 改变信任、任务、资源、路线意愿、知识和下一天事务。 |
| 5\. 营地行动 | 阅读、教学、维修、交易、分配和休息。 | 选择一次主要营地行动。 | 改变知识、车辆、资源、关系和仪式。 |
| 6\. 夜间结算 | 查看当天因果链。 | 只查看结果，不追加选择。 | 传播知识、形成习惯或制度、更新隐藏事件和夜间消耗。 |
| 7\. 结局检查 | 查看是否死亡、分裂、定居或继续前进。 | 若继续则进入下一天。 | 在第 12～20 天之间通常进入最终结局。 |

# 四、早晨阶段：NPC 每日事务

NPC 不是每天重复同一句请求。系统每天早晨根据 NPC 的需求、职业、所属群体、个人记忆、前一天对话、资源状态和历史事件，为每个存活 NPC 生成当天事务。

| **事务字段** | **玩家看到的内容** | **示例** |
|:--:|----|----|
| 需求 | NPC 当前最直接的生存或心理需求。 | 缺水、药品、疲劳、尊重、路线信息、寻找亲人。 |
| 目标 | NPC 今天想完成的事情。 | 请求优先分水、要求绕路、交换地图、学习维修。 |
| 对象 | 目标指向的人、群体、书籍或地点。 | 队长、另一群体、技术手册、旧医院。 |
| 紧急度 | 不处理会造成的后果。 | 低：可以延期；中：信任下降；高：离队、冲突或危险。 |
| 截止时间 | 事务最晚处理的时机。 | 当天夜间、下一次停歇或指定天数后。 |
| 后果 | 玩家接受、拒绝或延期之后的变化。 | 获得情报、消耗资源、改变路线、形成任务或提高分裂风险。 |

不是所有 NPC 每天都主动发起对话。只有满足条件并且紧急度足够的事务才会进入当天对话队列。

# 五、路线选择与移动阶段

| **路线** | **玩家理解** | **可能代价** |
|:--:|----|----|
| 安全路线 | 风险较低，适合资源紧张或成员受伤时使用。 | 消耗时间或燃料较多，资源收益较少。 |
| 资源路线 | 可能遇到加油站、仓库、医院或交易点。 | 怪物、道路事故和资源争夺概率较高。 |
| 未知路线 | 地图信息不足，可能通往隐藏地点。 | 路线判断错误、信息冲突和即时突发概率较高。 |

车队移动时不会进入常规对话树。战斗、怪物群、道路坍塌、车辆抛锚、火灾、污染区和短促求救信号会直接出现。系统根据路线、车辆噪音、灯光、时间、天气、燃料、损坏和历史事件判断是否触发。

玩家只能执行预先确定的行动，例如加速、熄火、绕行、诱敌、保护伤员或承受袭击。部分事件允许一个短促反应按钮，但不打开完整资源菜单。

# 六、停歇阶段：NPC 对话是主要玩法

抵达停歇点后，移动暂停，游戏按照紧急度显示 NPC 对话队列。玩家在这里进行大部分真正的思考和取舍。

- 接受请求，消耗资源并提高信任；

- 拒绝请求，保留资源但可能产生不满、私藏或离队；

- 追问信息，判断 NPC 说法是否可信；

- 承诺以后处理，把事务推迟到下一天；

- 用饮水、食物、药品、书籍、茶叶或香薰交换；

- 让其他成员回答，改变群体之间的关系；

- 暂缓处理，承担事务升级的风险。

对话结果会写入历史记录，并影响下一天的 NPC 事务、路线意见、知识传播、潜在成员招募和隐藏事件进度。

| **当天对话结果** | **下一天可能出现的内容** |
|:--:|----|
| 接受侦察员的路线请求 | 侦察员可能成为路线向导，其他群体可能要求补偿。 |
| 拒绝某个群体的药品请求 | 出现抗议、私藏、离队或新的群体冲突。 |
| 允许成员学习书籍 | 出现教学事务；知识接受度提高，可能形成新的职业。 |
| 交换地图或技术书 | 获得路线或资源，但原有知识减少，相关群体可能提出质疑。 |
| 在突发事件中保护某个群体 | 被保护群体信任上升，其他群体可能要求解释。 |

# 七、营地行动与书籍

完成主要 NPC 对话后，玩家可以执行一次营地行动：阅读书籍、教学、记录符号或路线、维修车辆、分配资源、使用茶叶与香薰谈判，或让成员休息。

| **书籍动作** | **玩家操作** | **长期结果** |
|:--:|----|----|
| 阅读 | 让能理解该类别的成员阅读。 | 增加理解度，为教学和知识传播做准备。 |
| 教学 | 让已经理解内容的成员传授给其他成员。 | 增加知识标签，可能形成维修、医疗、侦察或后勤职业。 |
| 记录 | 使用空白笔记本记录已验证的路线、符号、维修方法或交易规则。 | 让知识跨越成员死亡继续保存。 |
| 交换 | 把书籍交给其他群体换取资源、人员或信息。 | 立即获得帮助，但车队失去一部分长期知识。 |
| 燃烧 | 把书籍作为燃料。 | 立刻缓解寒冷或危机，但永久失去尚未传播的知识。 |

茶叶与香薰主要解决短期问题：缓解焦虑、促成谈判、换取情报、形成营地仪式和建立群体身份。它们也会带来饮水、燃料、暴露、垄断和公平感方面的长期影响。

# 八、夜间涌现结算

夜间系统不再追加玩家选择，而是统一处理当天行动产生的长期变化：

- 知识传播：判断谁读懂、谁教学、谁保存记录；

- 关系变化：计算资源分配、谈判、拒绝和保护行为造成的信任变化；

- 习惯形成：检查相同行为是否重复发生；

- 制度形成：判断习惯是否被多个群体接受；

- 隐藏事件进度：更新地图线索、无线电、符号和历史记录；

- 因果链生成：显示选择如何改变资源、人员和下一天事务。

例如：机械师阅读技术手册 → 教学给年轻成员 → 维修成功率提高 → 车辆没有抛锚 → 车队把零件优先分配给维修组 → 维修职业和资源分配规则形成。

# 九、第 2～11 天：车队逐渐形成自己的社会

第 2～4 天主要让玩家理解资源、NPC 对话、车辆和即时突发。第 5～11 天开始同时出现资源压力、车辆维修、群体关系、潜在成员招募、书籍传播、怪物追踪和隐藏事件。

玩家会逐渐发现，自己并不是只在管理资源，而是在决定哪个群体获得机会，哪些知识可以留下，哪些潜在成员能成为车队未来的一部分。

# 十、地图潜在成员

潜在成员可能出现在废弃加油站、医院、居民点、坍塌隧道、无线电信号地点、交易聚落和特殊事件中。玩家可能通过救援、谈判、交易或路线选择接触他们。

| **结果** | **影响** |
|:--:|----|
| 救下并招募 | 人口增加，资源消耗增加；新成员的数值会改变岗位效率和 NPC 事务。 |
| 救下但暂不招募 | 需要承担保护或等待风险；成员可能在下一天离开或被怪物杀死。 |
| 放弃救援 | 节省时间和资源，但失去该成员以及可能的数值优势。 |
| 即时突发中失去 | 成员可能在战斗、道路事故或怪物群中死亡，相关数值和事务从系统中移除。 |

# 十一、第 12～20 天：结局阶段

第 12 天开始，系统逐渐开放定居、重建家园、加入其他聚落、继续流动或保存知识的选择。只要满足结局条件，游戏可以在第 12～20 天任意一天结束。

| **结局形态** | **形成条件** |
|:--:|----|
| 城市 | 人口相对充足；技术知识被多人掌握；公共仓库或交易制度存在；基础设施能够维护。 |
| 城堡 | 外部威胁较高；防御、武器或装甲资源充足；权力集中；成员接受严格等级和配给制度。 |
| 村庄 | 人口较少但关系稳定；饮水和食物可靠；互助规则被接受；整体低噪音、低消耗。 |
| 流动聚落 | 车辆和维修能力较强；车队不固定定居；地图、交易和路线知识持续增长。 |
| 文化遗产 | 成员死亡或离散，但书籍、符号、路线记录或制度被保存。 |

# 十二、提前结束与特殊结局

- 饮水、食物、药品或燃料耗尽，且没有可执行补救行动；

- 车辆报废，无法维修，也没有可行的徒步或定居方案；

- 关键成员死亡，导致车队无法维持基础工作；

- 信任崩溃，成员分裂或另立车队；

- 主角在移动即时突发中死亡；

- 文化遗产：成员死亡，但知识、符号或制度被保存；

- 无名消失：成员死亡，也没有留下可传播的知识；

- 共存幻梦：主角死在路上，临死前梦见人类与异变生物共存，现实中尸体被怪物吞食。

# 十三、玩家一局游戏的核心感受

第一次游玩时，玩家先学会让车队活过一天，然后开始理解 NPC 的个人目标和群体冲突，最后意识到：玩家不是直接点击“建造城市”，而是在每天的对话、资源分配、救援、拒绝、教学、交易和即时突发中，让一个拥有独特关系、知识和制度的车队逐渐形成。

# 十四、技术执行要求

| **系统** | **必须记录** | **必须产生的结果** |
|:--:|----|----|
| NPC 日程系统 | NPC 需求、目标、对象、紧急度、截止时间、历史事务。 | 当天对话队列和下一天事务。 |
| 对话系统 | 玩家回应、资源变化、信任变化、承诺、拒绝和延期。 | 任务、关系、路线意愿、知识和潜在成员状态变化。 |
| 移动突发系统 | 路线、时间、噪音、灯光、车辆、人员和历史事件。 | 即时伤害、损坏、消耗、路线变化和事件日志。 |
| 涌现结算系统 | 阅读、教学、记录、交易、仪式、资源分配和保护行为。 | 知识、职业、习惯、制度、隐藏事件和因果链。 |
| 结局系统 | 人口、资源、车辆、信任、知识、制度、防御和威胁。 | 提前死亡、定居形态、文化遗产或特殊结局。 |

**结论：玩家的主要思考发生在 NPC 对话中，紧张感发生在移动即时突发中，长期变化发生在书籍传播、资源分配和群体关系中，最终结局由 12～20 天内积累出的社会状态共同决定。**
