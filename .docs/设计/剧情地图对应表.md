普通日并没有一张由日期独占的固定地图。地图由实际移动、当前事件、现场事务、扎营或真实抵达决定；本表不把十二张图强行按编号轮播。

|---|---|---|
|1|清点五人、车辆和物资，第一次准备与出发|**加油站开场**；晨间所有标签和首次出发前选路仍在加油站。确认行驶后显示横版公路；进入营地行动后才显示营地。|

## 其余场景与优先级

|场景|进入条件|离开/限制|
|---|---|---|
|篝火营地|真正进入营地、营地事件和夜间；后续普通晨间|不覆盖第1天加油站开场、实际聚落或商会位置。|
|帐篷内部|在营地/晨间等驻扎阶段查看成员、库存或书籍岗位|仅是当前营地内的规划视角；在医疗站/水塔停歇或第1天加油站不靠切标签跳进帐篷。|
|封闭隧道|第三章后选路明确选择支路时为“路线预览”；确认出发后N-C04为实际入口|退回后离开入口；在入口发生即时失败保留隧道现场。它不替代救援站。|
|雪地营地|第15—20天已真正进入雪区后的普通扎营|跨区日晨间及原地停留保留前区；早期北行不提前改变日期地貌。|
