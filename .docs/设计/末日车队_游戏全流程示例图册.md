平台：安卓手机版（横屏、触屏操控）｜ 视角：操控人物为 2D 横版侧视，其余界面为上帝视角（斜 45 度俯视）

依据：07_末日类型游戏策划案 · 04_结局与决策 · 01_核心概念 · 02_涌现系统

**文档说明**

1\. 用途：作为《末日车队》UI 美术与交互实现的对齐依据，按玩家实际操作顺序编号排列。

2\. 图片来源：全部由 GPT-Image-2.5 生成，主菜单与设置页以同一张风格参考图统一配色与控件，保证整套 UI 一致。

3\. 图号规则：图 01–08 主菜单与设置；图 09–22 关卡与系统流程（图 18 结算界面已按要求删除，编号留空）；图 23–30 休息点玩法（核心）；图 31–36 休息点场景库（可替换）；图 37–49 十三种结局插画；图 50–61 依据策划案「四、游戏玩法流程」4.1–4.3 制作的每日流程与即时突发配图（其中 58–61 即时突发采用上帝视角）。页面按图号升序排列（图 18 留空）；「流程总览」给出的是实际游玩顺序，两者配合使用。

4\. 分辨率：图 01–07 为 2048×1152；其余各图（含 13 张结局插画）均为 1536×864，可等比放大作为切图底稿。

5\. 平台基线：以安卓手机版为准——横屏、触屏操控，所有交互说明按手指点按 / 拖拽编写，界面中不出现键盘键帽与鼠标图标。

6\. 游戏类型与视角：HD-2D，两套视角按场景切换——操控队长走动 / 交谈 / 谈判时用 2D 横版侧视（镜头侧面正视，地平线在画面下方三分之一）；菜单、设置、大地图、赶路、战斗、结算与各类面板用上帝视角（斜 45 度俯视的伪 3D 场景）。两套视角都不允许第一人称与贴地特写。

7\. 玩法核心：休息点的选择。玩家操控队长在休息点走动、与队友交谈（分支选项）、分配有限物资，并在遇到其他车队时决定谈不谈、怎么谈。战斗只是路上的偶发遭遇，不承担玩法主线。

8\. 休息点场景库（图 31–36）：同一套休息点交互系统配 6 种可替换场景——营房帐篷内会议、篝火旁作战会、废弃加油站、隧道口避风、雪原营地、中立集市。做关卡时按章节替换场景背景即可，UI 与交互逻辑不变。

9\. 每张图下方固定给出「出现时机 / 画面元素 / 交互说明 / 设计要点」，便于直接转成需求条目。

10\. 本文档中的图片为示意稿，正式开发时以 UI 切图 + 引擎内实装为准。
