# 001｜0.7.0开发基准

正式工程仍为仓库根目录，Godot 4.7.2。克隆后执行`git lfs install`和`git lfs pull`，打开`project.godot`。APK、引擎、导入缓存和签名密钥不入仓库。

## 当前入口及功能

入口保持`scenes/boot.tscn → scenes/main.tscn → scenes/release_game.tscn`，不能改回菜单直接启动或静态预载完整游戏。菜单存档验证也不能静态预载`world_rules.gd`。

`src/game/save.gd`支持自动槽和六个手动槽，仍读取旧`final_autosave.json`。`src/ui/archive_screen.gd`由菜单和暂停页共用。旧存档兼容样本位于`tests/fixtures/v062_autosave.json`。

音乐由`src/audio/music_director.gd`单例管理，`data/music_catalog.json`选择曲目；角色活动由`data/member_activities.json`和`member_activity_layout.gd`选择，不改变玩法状态或随机数。

调试版本按F8可进入开发面板，路径重放使用独立存档目录；正式Android发行包不包含开发面板代码。`scenes/vehicle_side_2d_placement.tscn`是2D车辆调试入口。提供的工程没有保存任何2D车辆确认记录，正式场景不会采用默认位置；后续必须按项目AGENTS.md由用户逐场景确认。现有3D车辆参数保持原样。

## 资源维护

正式导出清单为`tools/mobile_export_resources.json`，与`export_presets.cfg`保持同步。新增动画帧、音乐、动态JSON资源时同时更新清单；当前校验器会递归核对预载、场景依赖及角色／音乐清单中的动态路径。

已有场景图片维持0.6.2的导入压缩；新增PNG保留原件，导入质量0.75，封面／图标0.7。不要整体覆盖来自未优化工程的`.import`文件。旧头像制作源图、预览和开发资料不进入APK。

新增Lucide五个资源图标的来源见`third_party/lucide/manifest.json`，ISC许可副本位于`assets/licenses/LUCIDE_LICENSE.txt`，已经随APK导出。

## 构建与验证

执行`tools/build_android_test.ps1`导入、构建、检查实际APK并签名。其他电脑可通过参数指定引擎、SDK、JDK及自己的测试密钥。只有使用同一签名才能直接覆盖已有安装。

`tools/check_final_game.ps1`包含新增功能检查；现有3项HUD适配断言仍失败，不能称整套检查全绿。PCK必须从空目录运行，避免借用源工程资源。完整结果与APK指纹见[0.7.0合并与手机资源验证](../发布/0.7.0合并与手机资源验证.md)。
