# 2026-10-12｜设置界面第一版

设置界面沿用月夜、荒城、车队和篝火，但改用没有标题文字的“正式版”视频。面板落在左侧与中部，留出右侧月亮和车队；半透明深蓝面板压低背景干扰，用暖金色标记当前选项、滑杆与完成按钮。

![声音设置](素材/2026-10-12/03_设置_声音.png)

第一版分为四栏：声音包括总音量、音乐、音效、环境与静音；画面包括品质、30 / 60 帧、亮度与动态背景；操作包括触控尺寸、不透明度、振动与惯用手；通用包括语言、阅读字号、字幕与自动存档。底部固定恢复默认和完成，避免返回入口被选项挤出屏幕。

![画面设置](素材/2026-10-12/04_设置_画面.png)

![操作设置](素材/2026-10-12/05_设置_操作.png)

![通用设置](素材/2026-10-12/06_设置_通用.png)

这次先确认美术与交互，不提前实现全部设置系统。滑杆、按钮和开关都可操作，切换分类保留本次运行的选择。动态背景开关已经实际控制主菜单与设置页的视频，其他选项目前仅改变设计稿状态；声音分组、画质、帧率、亮度、触控、振动、阅读与自动存档仍待后续接入，也没有配置文件持久化。

检查了四栏实际渲染、滑杆鼠标点击、动态背景切换、恢复默认、返回主菜单和进入游戏，以及 960×600 与 1560×720 的布局和点击坐标。既有 240 项 UI 流程检查通过。背景转码为 1920×1080、30 fps，并去掉音轨，原始 8K / 120 fps 文件不随游戏打包。
