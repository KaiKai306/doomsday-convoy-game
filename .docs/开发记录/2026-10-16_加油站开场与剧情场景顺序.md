# 加油站开场与剧情场景顺序

本轮修正第一张地图错误、旅途公路镜头不一致，以及已有场景只在独立预览中好看、却可能在正式剧情中出现过早的问题。

新游戏现在从废弃加油站开始。晨间清点、所有准备标签和第一次出发前的选路保持在这里；实际出发后切到横版公路，安排营地行动后才出现篝火。开局正文也对应雨棚、油桶和物资清点，去掉第一次晨间引用昨夜火灰和昨日路线的错位。

![真实新游戏第一屏](../美术/剧情场景接入/gas_station_main.png)

公路使用已有Harness任务生成的水平侧视原画，不再重复生成。按1916×821原图重新标注电线、杆体、灯具、护栏、地面和前景，三层共同裁切后等比放至2688×1152。保留的车位与素材库适配改为水平同向，轮胎基线和步行路径分开，取消原先的−13°路面旋转。正式场景随后按另一项用户要求撤车，车辆数据与素材库保留。镜头仍只支持±25画布像素的小幅视差。

![正式横版行走画面](../美术/剧情场景接入/journey_road_walk.png)

核对最终总稿与剧情节奏规范版后，医疗站放在第4日实际停歇，水塔放在第7日，第8日付费侦察只出现站外，第10日真正救援后才进入室内。聚落与商会取决于实际访问或完成登记，查看目标、预览人物卡、联系阵营不会获得抵达背景。营地不会沿用未清理的交易卡或加油站卡；无法到站的救援选择仍显示当前公路。巡游目标和隧道即时失败也保留相应现场。

详细逐日表、来源、分支条件见[剧情地图对应表](../设计/剧情地图对应表.md)。未固定地点的普通日使用真实路线和事件，不按图片数量编造二十个日期地点。

验证从17条真实结局路线和一条北行支线取得检查点，再通过正式主菜单进入的游戏界面恢复、查看、走动并截图，12个场景都有主界面和全屏行走证据。没有通过补资源或设置结局制造画面。场景选择、切页及行走前后比较完整状态与随机数，保持一致。
