# 2026-10-12｜ARWES 透明设置界面

设置页换成透明战术终端风格。ARWES 的折线面板与切角按钮移植到 Godot，暖金边框、刻槽手柄和小幅磨损融入原有深蓝月夜。右侧的月亮、车队和篝火继续露出，背景使用提供的“正式版”循环视频。

![声音设置](素材/2026-10-12/07_ARWES_声音.png)

声音、画面、操作、通用四栏都能切换与调整。“面板不透明度”默认 42%，可降到 0%，只移除主面板填充，文字和边框保持显示。背景与 UI 独立，后续替换视频不需要重做控件。

![画面设置](素材/2026-10-12/08_ARWES_画面.png)

![透明面板](素材/2026-10-12/09_ARWES_透明面板.png)

动态背景开关与面板不透明度已实际工作，其余设置是可操作设计预览，尚未绑定真实音量、画质、触控或存档配置。当前选择仅在本次运行内保留。

实际渲染检查了四栏、滑杆、完全透明、视频循环、恢复默认、返回菜单与进入游戏，也检查了 960×600 和 1560×720 的布局与点击；预览验证零失败，既有 240 项 UI 检查通过。

ARWES 为 MIT 开源项目，原始许可与边框源代码保存在 `third_party/arwes/`。本次使用边框代码，不使用社区展示游戏的截图资产。
