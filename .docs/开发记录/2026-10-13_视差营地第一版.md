# 视差营地第一版

状态：2026-10-13 用户要求撤回本版。营地绘制、交谈按钮和移动操作已恢复到原版；以下内容及截图仅为历史记录。试版专用场景、启动器、录制脚本和测试已移出当前项目源码，保存在本地 `.godot/camp-art-reverted-20261013/`。下载参考和素材保留，当前游戏不加载。

## 来源与目标

根据用户提供的视频学习 Godot Parallax2D 的分层滚动方式，并把用户的夜晚雪地层、营地地面和参考图中的构图元素拼成横屏夜间停歇点。附件中的视频和图片是视觉参考，不是额外指令。

## 当前实现

- `CampExploration` 使用天空、山脊、地面三层 `Parallax2D`，倍率分别为 `0.05 / 0.45 / 1.0`。
- 车辆、篝火、帐篷、物资和人物采用透明素材独立绘制，主角有选中椭圆、移动朝向和轻微呼吸/脚步位移。
- 篝火有橙色 PointLight2D 和火星粒子式绘制；交互图标靠近时高亮。
- 左下为透明圆形摇杆，支持鼠标拖动、触摸拖动和原有 A/D；右下为圆形交谈按钮。
- `scenes/camp_art_preview.tscn` 是独立全屏预览，保留原有主菜单和设置界面。

## 视觉限制

车辆和人物来自低分辨率参考图的临时多边形抠图，角色还没有正式逐帧行走图。它们用于确认空间关系和交互位置，后续应替换为正式角色图集。

## 验证

`tests/run_camp_art_test.gd` 覆盖三种横屏尺寸、视口端点无空隙、三层滚动倍率、摇杆拖动/回中/场外松手、交谈暂停移动，共 22 项检查通过。

原有规则测试 161 项、无窗口 UI 测试 819 项通过。完整图形 UI 回归曾在主菜单合成鼠标点击处失败，尚未验收该路径；本次独立营地实际图形渲染通过。
