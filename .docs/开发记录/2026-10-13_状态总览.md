# 2026-10-13：把状态查看做成指挥室总览

原成员弹窗能显示五人的文字摘要，但资源、旅途位置和个人处境需要分散查看。这次将用户的状态总览参考图转成游戏中的正式页面：在月夜指挥室里用三块旧金属面板集中呈现资源、停歇点和五名成员。

![实际游戏状态总览](素材/2026-10-13/状态总览/01_status_overview_1280x720.png)

## 从参考图到可交互页面

背景、地图、头像按 GPT 图片模型参数 `gpt-image-2.5-flare` 在后台生成。复用了 Harness 既有脚本的图片编辑接口，真实参考图随请求提交，提示词分别要求无字环境、无地点标记地图与五人头像图集；没有操控桌面 Harness 聊天窗口。环境与头像实际为2048×1152，地图实际为1254×1254。原图和生成记录保留在 `assets/ui/status_overview/`。

图片只提供环境和人物美术。资源文字、配给说明、细条、页码、地图地点、角色状态和返回按钮全部使用原生 Godot 控件，数值直接来自当前 GameState 与 DayLoop。地图十处地点每页五处；选择地点仅查看名称与进度。未出发时显示“今日目标”，到达后显示“当前”。

参考图给资源标了容量，但现有玩法没有库存上限，所以保留真实份数，细条只以初始储备作参考；超过初始储备时仍显示完整数量。水与食物显示基础配给可供几晚，燃料显示当前路线所需份数，缺货与低信任用暖黄提醒。

成员保留主角、老张、艾琳、阿杰、索菲亚和现有岗位。受伤、疲惫、不安来自个人健康、疲劳、信任，不把参考图片里的“缺水”状态直接变成尚未实现的规则。

![真实警示与第七天地点](素材/2026-10-13/状态总览/03_warnings_day_seven.png)

## 查看与返回

点按成员打开健康、疲劳、个人信任与最近记忆。长记忆限制在滚动区域里，底部返回按钮一直可见。Escape 先退出详情，再退出总览。

![成员详情](素材/2026-10-13/状态总览/05_member_detail.png)

总览打开时暂停自动行进与营地操作。底部按钮明确写“回到当前阶段”，关闭后恢复原阶段与原进度，不推进天数、不执行行动，也不结算资源。所有11种阶段都检查了关闭前后完整存档快照相同。

## 渲染中发现并修正的问题

首次实际渲染发现图片在设置显示尺寸前已按原图尺寸撑大，导致地图和头像越过面板。调整 TextureRect 的属性设置顺序后，图片按指定矩形覆盖裁切。地图底图放在原生路径绘制后面，确保连线和名称可见。资源条重新设置最终尺寸，避免主题字体高度把细条撑成色块；最后一个地点上移，标签留在地图内部。

截图通过不可见的 Windows 宿主窗口与 Godot SubViewport 获取，不移动鼠标、不模拟桌面键盘，也不弹出游戏窗口。

![窄横屏实际渲染](素材/2026-10-13/状态总览/06_status_960x600.png)
