# 五人头像统一替换

用户授权按五张角色四视图，通过桌面 DeepSeek Harness 生成并统一替换状态总览中的五人头像。初版存在主角和老张偏年轻、阿杰兜帽遮脸、艾琳戴帽、索菲亚短发戴帽等造型偏差。

正式文件位于 `assets/ui/status_overview/`：`captain.png`、`mechanic.png`、`medic.png`、`scout.png`、`quartermaster.png`，全部 512×512。列表和详情共用既有姓名映射，核对了主角成熟司机造型、老张灰白胡须、艾琳无帽收束发型、阿杰露出短发面部、索菲亚卷发与头顶眼镜。

Harness 会话为“末日车队角色四视图设计”，模型参数 `gpt-image-2.5-flare`，通过 `/v1/images/edits` 的 multipart `image` 上传从真实四视图裁出的单人参考。主角原图 1024×1024，其余四张 1254×1254；均保留原生输出，正式素材只做完整画面缩放。参考上传遇到断连后改用压缩 JPG 和串行执行，最终逐张保存结果并为下载设置超时。

修订目录 `assets/ui/status_overview/portrait_revision_20261013/` 保存原图、参考、提示词、生成脚本、`manifest.json`、五人完成标记 `READY.json`、安装记录 `installed.json`、旧头像备份 `previous_portraits/` 和实际渲染截图 `qa/`。前三张在逐张日志修复前已成功，事后补录记录显式标记 `record_recovered`；未知服务响应和耗时未填写。该目录 `.gdignore` 防止生成档案进入游戏资源导入。

`tools/prepare_status_portraits.py` 在替换前验证 READY 包含恰好五个路径、原图可读且为不小于512的正方形，并保留旧素材。`tools/prepare_status_art.py` 优先安装新版，重跑不会恢复旧图集头像。本次已实际重跑确认。

Godot 4.7.2 导入成功。不可见 Windows 宿主窗口内进行实际 OpenGL 渲染，状态总览现有测试结果：`STATUS_OVERVIEW_TEST_PASS checks=80 failures=0`。五人详情、总览、960×600 和 1560×720 适配截图已保存；五张详情逐一查看，面部、头顶、帽子和眼镜无截断。
