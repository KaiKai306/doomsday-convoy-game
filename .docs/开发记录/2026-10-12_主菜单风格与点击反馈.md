# 2026-10-12｜主菜单风格与点击反馈

主菜单与设置页统一为暖金战术风格。无字版车队视频作循环背景，主标题、四个菜单按钮和退出确认框成为独立 UI，使用 ARWES 折线与切角边框。菜单占左侧，右侧保留月亮、车队和篝火。

![主菜单](素材/2026-10-12/10_ARWES_主菜单.png)

按钮按下时短促缩小、金属边框闪亮，松手轻微回弹。同时播放自制低沉金属点击音。跳转先保留按压反馈，再淡出旧页面、滑入新页面；分类切换和退出确认也有过渡，转场期间拦截重复跳转。

[点击与跳转短视频](素材/2026-10-12/13_主菜单_点击与跳转.mp4)

点击音实际受设置里的总音量、音效和静音控制；滑杆拖动结束提供一次确认音。背景视频不带音轨，其他游戏音频尚未接入。

![退出确认](素材/2026-10-12/11_ARWES_退出确认.png)

![窄横屏](素材/2026-10-12/12_ARWES_主菜单_960x600.png)

实际渲染检查按钮按压与回弹、静音与零音量、无存档禁用、保存后继续、退出取消、设置往返、视频循环和关闭动画后的静态封面，以及窄 / 宽横屏布局和点击。预览检查零失败，既有 240 项 UI 检查全部通过。
