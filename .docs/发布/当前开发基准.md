# 末日车队当前开发基准

2026年10月19日，0.7.0。根目录《末日车队_游戏设计最终总稿.docx》为唯一设计基准，旧资料冲突时按总稿执行。

当前包含20天剧情与17主结局框架、六槽手动存档、场景音乐、队友活动动画、手机资源与安卓启动优化。0.7.0 ARM64测试签名APK约150 MB，新增资源已压缩，原图保留；已在Android模拟器验证，实体手机由玩家自行安装复测。构建与验证见[0.7.0合并与手机资源验证](0.7.0合并与手机资源验证.md)，后续开发见[001交接说明](../协作交接/001_0.7.0开发基准.md)。玩家公告记录在根目录[CHANGELOG.md](../../CHANGELOG.md)。

## 当前入口

`project.godot → scenes/boot.tscn → scenes/main.tscn → scenes/release_game.tscn`。主菜单新游戏和继续均使用 `src/game` 新引擎。旧 `src/core`、`data/demo_content.json` 及旧测试只作历史参考。

`data/final/content.json` 从最终Word导入并保留其SHA256，包含109卡、20日日程、8重要节点、30配件、15固定地点、15随机来源、17主结局与6类妹妹尾声。内容数量与规则验证分别记录。
