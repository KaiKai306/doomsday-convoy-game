## 克隆与构建

安装 Git LFS 后克隆并取回原图：

```powershell
git clone https://github.com/KaiKai306/doomsday-convoy-game.git
cd doomsday-convoy-game
git lfs install
git lfs pull
```

使用 Godot 4.7.2 打开 `project.godot`，首次导入会根据提交的 `.import` 参数生成压缩纹理。原图和导入缓存的体积不等于最终安装包体积；约87 MB是测试APK的测量结果。

Android 导出使用 **Android APK** 预设，需要相应导出模板、JDK与Android SDK。预设不包含签名私钥，默认导出未签名APK。本地测试包另用调试密钥签署；正式发行时需设置应用包名、图标及发行签名，并进行真机测试。

APK 位于本地 `export/android/`，引擎、导入缓存、密钥与导出包均不进入 Git。没有创建公开平台版本或发布 GitHub Release。

后续每次可交付的小版本都更新根目录 `CHANGELOG.md`，用简短玩家公告记录已完成的变化。开发过程另写 `.docs/开发记录/`。
