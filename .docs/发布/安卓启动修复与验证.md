## 原因与修复

旧APK的Android日志明确报错：`Preload file "res://scenes/release_game.tscn" does not exist`。导出白名单漏了主菜单预载的游戏场景，导致脚本解析失败，应用进程仍在但没有游戏画面。

入口改为 `project.godot → boot.tscn → main.tscn → release_game.tscn`。独立启动页不预载主菜单或美术，先提交可见画面，再后台请求菜单资源。百分比对应资源加载、菜单初始化与首帧呈现；失败时保留提示和重试按钮，诊断写入应用自己的 `user://startup.log`。

同时修复车辆页对原始GLB的依赖，改为读取已打包的Godot模型场景。1个网格的变换与包围盒核对一致，没有改动车辆位置、角度、缩放和镜头配置。
