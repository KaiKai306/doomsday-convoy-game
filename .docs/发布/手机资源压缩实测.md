## 压缩方式

- 调整 511 张较大二维纹理的 `.import` 参数：460 张场景/营地图采用 Lossy 0.4，51 张人物、车辆、界面细节图采用 Lossy 0.8。这里的数值是编码器质量参数，不代表保留相同比例的画质。
- 小图标、SVG、原始 PNG/JPG、3D 模型、音视频编码均保持原样。没有降低图片尺寸，没有改动任何走路坐标、相机参数或车辆构图。
- 检查全部 511 张实际生成的纹理，尺寸与原图一致；有透明通道的图片逐像素核对 Alpha，差异为零。RGB 使用有损压缩，细碎纹理会有一定损失。
- 补上 Android 导出必需的 `textures/vram_compression/import_etc2_astc=true`。二维压缩仍使用磁盘有损纹理，没有切换渲染器或把所有图片强制转为 ETC2。
- 将 54 项确认不供正式玩法使用的资源移出 APK 清单，工程原件全部保留：2 个角色姿势预览模型、1 个已被新模型替代的车辆模型、41 张旧地图整图预览、8 张界面制作源表/参考图、旧标题图与视频。保留正式三层地图、横版地图整图、最终头像、模块图和正在使用的车辆模型。菜单与设置共用的背景图/视频完整保留。

地图路径会动态拼接，不能只凭没搜到完整文件名来删除。此次核对了 `walk_backdrop.gd`、`location_backdrop.gd`、场景依赖与两套界面的实际加载逻辑；例如 `garage_clean_source.png` 和 `garage_repair_20261016/source.png` 虽然名称带 source，仍在正式界面使用，因此保留。

压缩主要减少安装包下载量。由于分辨率不变，纹理解码后的内存占用没有同比减少；运行内存与 GPU 压缩需要后续依据真机表现另行评估。
