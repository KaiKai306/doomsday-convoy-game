# 末日车队

面向安卓横屏的 2D 末日生存经营与叙事决策游戏，使用项目自带的 Godot 4.7.2 stable。

当前是 **0.3 五日体验切片**：五个人带一辆旧车出发。每天完成准备、选路、自动行进、营地探索与成员对话、一次营地行动和夜间结算。完整版本的徒步起步、车辆成长和 12–20 天旅途尚未实现。

## 运行

用本目录的 `Godot_v4.7.2-stable_win64.exe` 导入 `project.godot`，运行主场景 `scenes/main.tscn`。

- 三条路线分别提供安全通行、物资补给和路线档案。
- 出发前选择低噪音、快速或绕行；车队约七秒后自动抵达。
- 抵达后切换到侧视营地；点按地面移动，或按住屏幕左右方向。镜头跟随队长。
- 靠近队员后点按交谈，按优先队列逐条回应请求；可以先查看其他队员近况。
- 交谈期间停止移动；结束交谈可以原地继续探索，不会把请求自动记成延期。
- 选择前可看到代价和次日影响；桌面调试支持 A / D 移动、E 或空格交谈。
- 维修、阅读、教学与记录、休息均改变实际状态；每晚只做一次主要行动。
- 阅读手册后两次教学与记录，会形成共同维护习惯，之后每晚耐久 +3。
- 五日可获得“仍在路上”或“知识的火种”结果；配给不足、车损、信任、疲劳或无法出发会提前结束。
- 暂停菜单保存 / 读取，主菜单继续游戏；存档包含行进进度、事务游标、营地位置与打开的对话。

存档版本已升为 2，旧版 1 存档不兼容，会提示重新开始。资源不足时不会免费执行行动。所有场景仍为程序绘制占位，没有把策划图册当作正式背景。

0.3 继续兼容 0.2 的版本 2 存档；旧存档没有营地位置时从入口恢复，不自动打开对话。

## 目录

- `scenes/`：主场景与每日体验场景。
- `src/core/`：状态、阶段命令、内容读取及存档。
- `src/ui/`：界面、主题和可替换场景绘制。
- `data/demo_content.json`：成员、路线、事务、营地动作、五处地点和结果文案。
- `tests/`：规则与 UI 流程验证。
- `.docs/设计/`：原始策划与图册。
- `.docs/开发/`：实现约束及设计决策。
- `.docs/开发记录/`：供 Game Jam 帖子使用的开发过程与截图素材。

## 验证

PowerShell 中运行：

```powershell
& '.\Godot_v4.7.2-stable_win64.exe' --headless --path . --script tests/run_day_loop_test.gd
& '.\Godot_v4.7.2-stable_win64.exe' --headless --path . --script tests/run_ui_test.gd -- 'E:/AI_Workspace/临时文件/2026-10-11/convoy-qa'
```

UI 测试第二个命令的目录用于测试存档，可替换为当天任务临时目录。加上 `--capture` 且去掉 `--headless`，可输出各阶段截图。

规则覆盖两种五日结果、资源 / 车辆 / 疲劳 / 信任失败、跨阶段与重复操作、对话队列、次日因果、怪物追踪、营地边界与交谈范围、存档往返和损坏存档保护。UI 验证实际鼠标 / 屏幕触摸事件、多指方向、松手停止、镜头坐标、暂停、五日完整流程、存读档及横屏比例。最新一轮通过 66 项规则检查和 117 项界面检查。
