# 末日车队

《末日车队》是一个面向横屏手机端的 2D 末日生存经营与叙事决策游戏 Demo，使用 Godot 4.7.2 开发。当前先验证玩法和界面版式，正式背景美术稍后替换。

## 当前开发基线

- 引擎：Godot 4.7.2 stable
- 首要平台：安卓横屏；开发期保留键鼠输入，便于桌面调试
- 当前阶段：先做可运行 Demo；界面按图册排版，背景使用纯色、渐变和几何占位元素
- 核心循环：早晨事务 → 路线选择 → 自动移动与即时突发 → 停歇对话 → 一次营地行动 → 夜间结算
- 第一阶段目标：先完成主菜单版式和第 1 天可玩循环，再扩展到 1 条路线、5 个停歇点、3 个车辆阶段、4–5 种资源、1 种主要怪物行为、10–12 天循环和 4–6 个可验证结局

## 目录

- `scenes/`：Godot 场景文件
- `src/core/`：全局状态、规则和数据模型
- `src/ui/`：界面与交互脚本
- `data/`：Demo 初始内容和路线配置
- `tests/`：Godot 无界面规则测试
- `.docs/设计/`：现有策划案、玩法流程和示例图册
- `.docs/开发/`：开发路线、技术约定和待确认事项
- `CONTRIBUTING.md`：协作提交和交接约定

## 启动

用项目内的 `Godot_v4.7.2-stable_win64.exe` 导入本目录，或在 Godot 项目管理器中选择本目录。主场景是 `scenes/main.tscn`。

## 文档入口

从 [开发文档索引](.docs/开发/00_开发文档索引.md) 开始。设计原文暂时保留在 `.docs/设计/`，开发决策和变更记录写入 `.docs/开发/`。

## 自动验证

使用项目内 Godot 4.7.2 运行 `tests/run_day_loop_test.gd`，可验证两天循环、NPC 事务、对话因果、资源消耗、资源下限和存档快照恢复。

## 当前 Demo 已有

- 中文主菜单和图册版式占位界面。
- 第 1 天和第 2 天的每日循环。
- 结构化 NPC 当日事务、信任和下一日因果。
- 脚本绘制的星尘、火星、月亮呼吸光和阶段过渡动画。
- 主菜单和每日 Demo 支持横屏视口安全边距与按视口缩放。
- 暂停菜单已接入保存、读取、继续和返回主菜单按钮。
