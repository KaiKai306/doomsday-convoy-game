当前版本0.6.1，Godot 4.7.2。主菜单已接入按《末日车队 游戏设计最终总稿》实现的二十天可玩框架，支持完整旅程、十七主结局、保存继续和重试当天。

旅途界面已接入按实际玩法状态切换的场景美术，主角使用已确认的行走动画与B版站姿，队友仍使用功能占位。APK 已在本地构建并验证签名，尚未真机验证或上传 TapTap。

## 运行

仓库中的大体积图片、模型和音视频使用 Git LFS，克隆后先执行：

```powershell
git lfs install
git lfs pull
```

仓库同步正式运行资源、代码、设计与版本文档。未接入的素材库、完整美术制作归档、本地引擎、导入缓存和 APK 留在本地，详见[仓库与本地素材说明](.docs/发布/仓库与本地素材说明.md)。

用Godot 4.7.2导入根目录的 `project.godot`，按F5运行，从主菜单选择新游戏或继续。本地引擎也可直接运行：

```powershell
& '.\Godot_v4.7.2-stable_win64.exe' --path .
```

启动入口为 `scenes/boot.tscn`，加载后进入 `scenes/main.tscn`，游戏场景为 `scenes/release_game.tscn`。当前使用 `src/game` 新引擎；`src/core` 和旧十日场景仅作历史参考。

## 游玩

每天依次进行晨间准备、路线选择、途中事件、停歇事务、唯一营地行动和夜间结算。准备可以选择“不行动”；每天最多两项主要事务，营地行动另限一次。资源不足会禁用行动，失败命令不会扣除部分费用。

顶部切换行程、成员、库存、车辆配件、书籍岗位、阵营事务、目标和因果记录。左侧正文、右侧行动列表都可滚动。目标页列出未满足的条件；正常结局需要实际到达并完成行动，再经当夜配给和伤亡核验。

第2、5、8、10、12、15、18、20天是重要节点。妹妹第5天正式求救，第10天按真实情报、距离、岗位、物资与车况救援，成功后按人口处理入队或安置。

新游戏从废弃加油站开场，确认行驶后进入横版公路，再进入营地阶段。停歇或营地可进入侧视走动，用A/D、方向按钮或点地面移动，靠近队友后按E、空格或点交谈。Esc返回当前页面或暂停。重试当天须确认，会撤销当天全部收益、消耗、招募与伤亡，恢复晨间快照并更换随机种子；此前日期的历史保留。

## 验证

```powershell
& '.\tools\check_final_game.ps1'
& '.\tools\check_final_game.ps1' -GraphicalUI
```

2026年10月17日结果：规则40项、系统36项、回归56项、界面71项、17结局1733次命令、剧情场景4251项、地貌2413项通过。0.6.1启动成功/失败/重试、实际APK612项资源与隔离PCK907项检查通过；53张地图1170项为0.6.0美术基准。现有行走输入检查仍有3项横屏HUD适配断言失败（960×600、1560×720、2340×1080），与修复前一致，整套检查并非全绿。

固定结局记录在 `tests/fixtures/final_endings_paths.json`，运行时不直接补资源或设置结局。回归另覆盖救援到南边定居及第20日收束的逐步磁盘读档。界面检查覆盖四种横屏尺寸、109张卡预览、真实十日救援、确认重试和营地触控释放。

日志在 `.godot/final-checks/`，渲染截图在 `.godot/final-qa/`。加 `-FindEndingPaths` 可重新搜索路线，结果写到 `.godot/final_endings_paths.json`，不自动覆盖固定资料。

当前检查不等于全部随机组合或109张卡所有选项的穷尽验收。玩家试玩、45至75分钟节奏和平衡、正式美术、设置持久化与部分系统绑定、安卓真机及TapTap测试包仍需后续完成。本机引擎的Windows根证书读取提示另记在日志；本轮离线玩法、存档和渲染检查正常完成。

## 场景美术与行走（2026-10-15）

现有五张地图与新增七张地图均已接入正式玩法：旅途公路、医疗站、水塔、救援站外部及室内、聚落接纳点、中立集市。`src/game/location_catalog.gd` 根据实际阶段、抵达地点和事件选择场景；`camp_walk.gd` 沿各图单独标注的地面移动，点击远处墙面或天空不会离开路径。车辆按当前车队数量显示，室内不显示车辆。

七张新增图已于2026年10月16日换成通过DeepSeek Harness请求GPT 2.5重制的版本，按既有营地、加油站等场景统一画风。7张原画与7张远景补画均已完成；透明分层、行走路线及停车位按新图重新标注，原图和上一版素材均保留。原画实际1916×821，裁切后等比缩放至2688×1152。场景仅支持有限幅度视差，公路不是无限滚动地图。

2026年10月16日最终复验：场景与行走154项、剧情正式界面4154项（12处场景、24张真实玩法截图）、车辆73项、主角动画13项通过；规则40项、系统36项、回归56项、界面及图形复跑各33项、17结局1733次合法操作均失败0。检查保留玩法状态和随机状态，未补资源或直接设置结局来展示场景。

当前开局已改为加油站，公路已改成水平侧视。第4日医疗站、第7日水塔、第8日入口侦察、第10日救援内外，以及后半程聚落/商会等背景，按实际到达和事件切换。查看目标与卡片不会提前抵达，旧机会不会覆盖营地。
