# 末日车队

《末日车队》是一个面向横屏移动端的 HD-2D 末日生存经营与叙事决策游戏原型，使用 Godot 4.7.2 开发。

## 当前开发基线

- 引擎：Godot 4.7.2 stable
- 首要平台：安卓横屏；开发期保留键鼠输入，便于桌面调试
- 核心循环：早晨事务 → 路线选择 → 自动移动与即时突发 → 停歇对话 → 一次营地行动 → 夜间结算
- 第一阶段目标：完成 1 条路线、5 个停歇点、3 个车辆阶段、4–5 种资源、1 种主要怪物行为、10–12 天循环和 4–6 个可验证结局

## 目录

- `scenes/`：Godot 场景文件
- `src/core/`：全局状态、规则和数据模型
- `src/ui/`：界面与交互脚本
- `.docs/设计/`：现有策划案、玩法流程和示例图册
- `.docs/开发/`：开发路线、技术约定和待确认事项

## 启动

用项目内的 `Godot_v4.7.2-stable_win64.exe` 导入本目录，或在 Godot 项目管理器中选择本目录。主场景是 `scenes/main.tscn`。
